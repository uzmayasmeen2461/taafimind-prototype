# TaafiMind — competition prototype

Consent-based routine awareness and an optional native-audio wellbeing companion.

[Download the Android prototype](https://github.com/uzmayasmeen2461/taafimind-prototype/releases/latest)

This repository distributes an Android development APK and reviewer instructions;
it contains no application source or credentials. Android 8 or later and internet
access are required. The backend is hosted on Render; no Mac or USB is required.
A time-limited reviewer access code is supplied **privately** by the submitter.
The download alone does not grant live AI access. Never post the code here.

The demonstration uses **labelled sample sleep check-ins** to illustrate a routine
change, followed by an optional live conversation. It does not demonstrate measured
sleep, continuous monitoring, stress/anxiety detection or a clinical assessment.

Install `TaafiMind-Demo-Render.apk`, then follow `Reviewer-Quick-Start.txt` from the
release. This is a development prototype, not a Play Store or production release.
The public APK may be downloaded by anyone; use fictional, non-sensitive input.
Free hosting may take about a minute to wake; provider quotas and availability apply.

Live audio is transmitted through the backend to Google/Gemini only after explicit
consent. Provider terms and retention/data-use limitations apply. The app does not
save raw microphone audio. Accepted voice defaults store approximate conversation
text encrypted on the device and may share bounded recent text for continuity;
these preferences can be changed separately in Privacy. Journals and videos are
not uploaded automatically. The reviewer code is saved encrypted and can be removed.

TaafiMind offers wellbeing reflection and human-support guidance. It does not
diagnose, provide psychiatric treatment or reliably detect emergencies.
